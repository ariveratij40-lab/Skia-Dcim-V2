# Fases completadas

Este directorio conserva las especificaciones y el resultado documentado de las fases formalmente completadas y aprobadas.

Mover una fase aquí requiere que sus criterios de aceptación y validaciones estén documentados; un fallo conocido no debe ocultarse ni presentarse como aprobado. Su registro debe incluir identificador, rama, commit SHA aprobado, fecha de aprobación, alcance, pruebas, resultados y pendientes conocidos. El SHA aprobado es el baseline técnico de la fase.
