# Fases activas

Este directorio contiene las especificaciones de las fases actualmente autorizadas. Cada especificación debe definir objetivo, alcance, exclusiones, criterios de aceptación, riesgos y pruebas aplicables. Cuando afecte base de datos, migraciones, RLS, autenticación, multi-tenancy, Docker, Nginx, infraestructura o despliegue, también debe incluir una estrategia de rollback o explicar por qué no aplica.

La existencia de una propuesta fuera de este directorio no autoriza su implementación.
